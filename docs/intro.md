# Math Study

Este site e um roteiro de estudo de matematica. A ideia nao e correr por
formulas, mas construir dominio: entender o problema que motivou cada conceito,
ver exemplos concretos, representar visualmente e so depois formalizar com
simbolos.

## Ordem recomendada de estudo

Estude os capitulos nesta ordem:

1. [O que e matematica](./historia/o-que-e-matematica)
2. [Matematica basica: dos numeros as funcoes](./matematica-basica/)
3. [Fator comum em evidência](./matematica-basica/fator-comum-em-evidencia)
4. [Produtos notaveis](./matematica-basica/produtos-notaveis)
5. [Funcao quadratica](./funcoes/funcao-quadratica)

Essa ordem segue a dependencia entre as ideias. Primeiro vem a pergunta maior:
o que a matematica tenta organizar? Depois entram as operacoes, os tipos de
numero e a passagem para algebra. Em seguida, fatoracao e produtos notaveis
preparam o terreno para estudar funcoes quadraticas com menos memorizacao.

## Como estudar cada pagina

Em cada pagina, siga a sequencia:

1. leia o problema motivador;
2. entenda para que o conceito serve;
3. acompanhe a intuicao em linguagem comum;
4. observe o modelo visual;
5. so entao use simbolos e formulas;
6. resolva os exemplos antes de olhar os exercicios;
7. justifique as respostas com palavras.

Antes de avancar, voce deve conseguir explicar a ideia central sem depender de
uma formula decorada.

## Quando revisar

Volte uma pagina quando:

- uma formula parecer uma regra solta;
- voce conseguir calcular, mas nao souber explicar por que funciona;
- um exercicio misturar conceitos e voce nao identificar qual ideia usar;
- uma definicao parecer correta no papel, mas sem sentido em uma situacao
  concreta.

O objetivo e estudar menos coisas por vez, mas com entendimento suficiente para
usar a matematica em problemas novos.
