# Math Study

Este site é um roteiro de estudo de matemática. A ideia não é correr por
fórmulas, mas construir domínio: entender o problema que motivou cada conceito,
ver exemplos concretos, representar visualmente e só depois formalizar com
símbolos.

## Ordem recomendada de estudo

Estude os capítulos nesta ordem:

1. [O que é matemática](./historia/o-que-e-matematica) — a pergunta maior: o que
   essa linguagem tenta organizar?
2. [Números e operações](./numeros-e-operacoes/) — operar com números
   conhecidos, e ampliar que tipo de número se aceita.
3. [Álgebra](./algebra/) — escrever a regra que vale para qualquer número, e
   reescrevê-la sem mudar o que ela vale.
4. [Equações](./equacoes/) — descobrir o valor que a situação não informa.
5. [Funções](./funcoes/) — deixar de perguntar "quanto vale" e passar a
   perguntar "como uma quantidade depende de outra".
6. [Revisão geral](./revisao-geral) — o arco inteiro em exercícios que misturam
   os capítulos.

A ordem segue a dependência entre as ideias, e cada capítulo abre dizendo o que
herda do anterior. Aritmética sustenta a álgebra; a fatoração da álgebra é o que
resolve equações; e as raízes de uma equação são o que localiza um gráfico no
capítulo de funções.

## Como estudar cada página

Em cada página, siga a sequência:

1. leia o problema motivador;
2. entenda para que o conceito serve;
3. acompanhe a intuição em linguagem comum;
4. observe o modelo visual;
5. só então use símbolos e fórmulas;
6. resolva os exemplos antes de olhar os exercícios;
7. justifique as respostas com palavras.

Antes de avançar, você deve conseguir explicar a ideia central sem depender de
uma fórmula decorada.

## Quando revisar

Volte uma página quando:

- uma fórmula parecer uma regra solta;
- você conseguir calcular, mas não souber explicar por que funciona;
- um exercício misturar conceitos e você não identificar qual ideia usar;
- uma definição parecer correta no papel, mas sem sentido em uma situação
  concreta.

O objetivo é estudar menos coisas por vez, mas com entendimento suficiente para
usar a matemática em problemas novos.
