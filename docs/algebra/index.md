# Álgebra: escrever a regra, não apenas o caso

O capítulo anterior calculava com números conhecidos. Este capítulo responde a
outra pergunta:

> Como escrever uma regra que vale para **qualquer** número, e como reescrevê-la
> numa forma mais útil?

Álgebra não é aritmética com letras difíceis. É aritmética com o **caso geral**
no lugar do caso particular — e, uma vez escrito o caso geral, a possibilidade
de mudar a forma da escrita sem mudar a quantidade que ela representa.

## O que vem antes

Tudo aqui se apoia em [Números e operações](../numeros-e-operacoes/). Três
ideias daquele capítulo voltam o tempo todo:

- a **distributiva**, de [operações básicas](../numeros-e-operacoes/operacoes-basicas):
  é ela que autoriza abrir e fechar parênteses, e é a base de todos os produtos
  notáveis e de toda fatoração;
- as **regras de sinal**, de [números negativos](../numeros-e-operacoes/numeros-negativos):
  metade dos erros de álgebra é erro de sinal, não de método;
- **potências**, de [potências](../numeros-e-operacoes/potencias): $x^2$ é o
  mesmo $x \times x$ de sempre, só que a base agora é desconhecida.

Se alguma delas estiver enferrujada, o conserto está lá, não aqui.

## A pergunta que organiza o capítulo

Uma mesma quantidade pode ser escrita de várias formas:

$$
x^2 + 5x + 6 \qquad\text{e}\qquad (x + 2)(x + 3)
$$

As duas valem o mesmo para qualquer $x$ — teste com $x = 1$: as duas dão 12. O
que muda é o que cada escrita **deixa à vista**. A primeira é fácil de calcular;
a segunda mostra que a expressão é um produto, e é a única das duas que responde
de imediato onde a expressão vale zero.

O capítulo percorre esse caminho nos dois sentidos:

- **expandir** — de produto para soma, o que os produtos notáveis fazem;
- **fatorar** — de soma para produto, o que o fator comum, o agrupamento e os
  trinômios fazem.

Fatorar é o sentido difícil, e é o que o próximo capítulo vai precisar.

## Para que isso serve?

- escrever a regra de um preço, de um consumo ou de um salário uma vez só, em
  vez de refazer a conta para cada caso;
- simplificar uma fórmula antes de calcular, o que reduz erro e trabalho;
- reconhecer que duas fórmulas diferentes descrevem a mesma coisa;
- e, dentro da matemática, preparar o terreno para resolver equações e estudar
  funções sem depender de memorização.

## O que vem depois

O capítulo de [Equações](../equacoes/) usa a fatoração deste para descobrir
**onde uma expressão vale zero**. Antes de avançar, confira se você consegue
expandir $(x+3)(x-2)$ e voltar de $x^2 + x - 6$ à forma fatorada — os dois
sentidos, não só o primeiro.
