# Revisao geral

## Como as ideias se conectam

Veja a escada conceitual:

```text
operacoes
  -> negativos
  -> fracoes
  -> decimais e porcentagem
  -> potencias
  -> raizes
  -> expoentes fracionarios
  -> expressoes
  -> equacoes
  -> funcoes
```

Cada degrau amplia o anterior.

Operacoes permitem calcular. Numeros negativos permitem representar direcao,
perda e valores abaixo de uma referencia. Fracoes e decimais permitem lidar com
partes. Porcentagens tornam comparacoes de partes mais praticas. Potencias
representam repeticao multiplicativa, area, volume e crescimento. Raizes
desfazem potencias para recuperar medidas. Expoentes fracionarios conectam
potencia e raiz na mesma notacao. Expressoes algebricas transformam padroes em
linguagem simbolica. Equacoes permitem descobrir valores desconhecidos. Funcoes
descrevem relacoes completas entre grandezas variaveis.

## Exercicios de dominio

Faca poucos exercicios, mas justifique cada resposta. O objetivo nao e apenas
calcular: e explicar por que o procedimento faz sentido.

## Revisao curta

Matematica basica e a base para transformar situacoes concretas em modelos.
Operacoes organizam acoes com quantidades. Numeros negativos ampliam a reta
numerica. Fracoes, decimais e porcentagens representam partes. Potencias lidam
com repeticao multiplicativa. Raizes desfazem potencias. Expoentes
fracionarios escrevem raizes dentro da linguagem das potencias. Expressoes
algebricas representam regras. Equacoes descobrem valores desconhecidos.
Funcoes descrevem como uma quantidade depende de outra.

Antes de avancar, voce deve conseguir explicar, com palavras, o que cada
simbolo esta fazendo. Se uma regra parece apenas decorada, volte ao exemplo
concreto e ao modelo visual.
